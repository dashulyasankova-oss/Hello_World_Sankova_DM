Курс «Веб-разработка с нуля»

Этот курс предназначен для начинающих, которые хотят освоить создание современных веб-сайтов. Мы пройдём путь от основ HTML до публикации готового проекта в интернете.

1. Основы HTML

HTML — это язык разметки, который формирует структуру веб-страницы. Здесь мы изучаем теги, атрибуты, заголовки, абзацы и списки.

1.1 Структура HTML-документа

Любой HTML-файл начинается с декларации <!DOCTYPE html> и содержит теги <html>, <head> и <body>. В head помещаются метаданные, а в body — видимое содержимое.

1.2 Текстовые теги и форматирование

Заголовки от h1 до h6 создают иерархию, теги <p> отвечают за абзацы, а <strong> и <em> придают тексту смысловое выделение.

1.2.1 Спецсимволы и HTML-entities

Символы вроде <, > и & имеют специальное значение в HTML. Для их отображения используются замены: &lt;, &gt;, &amp;. Также применяется неразрывный пробел (&nbsp;) для связки слов.

2. Основы CSS

CSS отвечает за внешний вид страницы: цвета, шрифты, отступы, расположение элементов. Без CSS страница выглядит как чёрно-белый документ.

2.1 Селекторы и свойства

Селекторы указывают, к каким элементам применять стили. Например, селектор p { color: red; } сделает красным весь текст в абзацах.

2.2 Блочная модель

Каждый элемент на странице — это прямоугольник с margin (внешний отступ), border (рамка), padding (внутренний отступ) и content (содержимое). Понимание блочной модели — ключ к вёрстке.
