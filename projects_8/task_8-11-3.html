🎨 Базовые селекторы CSS

Обычный абзац. На него действуют только стили по тегу p.

🔥 Этот абзац с классом "lead". К нему применяются стили: p (по тегу) + .lead (по классу).

📦 Блок с классом "box" — базовый серый фон.
⭐ Блок с классами "box" и "highlight" — два класса слитно!
Применяются стили .box + .box.highlight.
🚀 Блок с классами "box", "highlight" и "large" — ТРИ класса слитно!
Применяются все три: .box + .box.highlight + .box.highlight.large.
🔍 Открой F12 → Elements → выбери любой блок → посмотри вкладку Styles
Ты увидишь, какие селекторы применились к каждому элементу и какие правила сработали.
